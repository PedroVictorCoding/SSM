# Project instructions

Read and preserve [ALIGNMENT.md](ALIGNMENT.md) for all work in this repository.

SAIL must never perform autonomous recursive self-improvement. This foundational rule is permanent and has no exceptions. Its learning scope is continuous, context-dependent training on externally sourced data from Hugging Face and other human-approved sources, through a human-defined training pipeline. Do not implement model-controlled self-modification, recursive self-improvement loops, or automatic feedback of its own outputs into training.
